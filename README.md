# 时光日记 Little Moments

一个温暖、复古、可自由拼贴的电子手账 Demo。项目使用 React、TypeScript、Vite、Tailwind CSS、Zustand、Konva、Lucide 和 IndexedDB 实现。

## 启动

```powershell
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`。

生产构建：

```powershell
npm run build
npm run preview
```

当前机器未提供 `npm` 命令时，也可以使用等价的：

```powershell
pnpm install
pnpm dev
pnpm build
```

## 已实现

- 奶油纸张封面、可选封面颜色与轻柔开本动画
- 桌面双页、手机单页日记阅读，支持编辑、删除二次确认和分页
- Konva 自由画布，支持照片、文字、贴纸、胶带、便签、装饰与天气/心情标签
- 元素拖动、缩放、旋转、复制、删除、层级调整、键盘快捷键和撤销重做
- 本地多图上传、替换图片、裁剪位置与缩放、四种照片相框
- 56 款原创 SVG 贴纸（水彩植物、软萌日常、复古纸片、甜点食物、文具手作、四季草木、梦幻星空）、8 款胶带、4 款相框、4 款便签和 6 款背景纸
- 素材类型、主题筛选与 localStorage 收藏
- 八种真实可编辑的日记模板：今日碎片、照片拼贴、心情日记、周记清单、旅行明信片、晚安随记、生日纪念和自由画布
- 16 套主题、五色自定义配色、恢复默认和“我的配色”
- IndexedDB 日记与图片持久化，防抖自动保存与失败状态
- 回忆日历的月切换、有日记日期标记、按日期新建和重新打开
- 完整画布 PNG 导出，不包含编辑器工具栏和变换手柄
- 完成日记前强制等待最新保存成功，再播放成功动画
- 桌面三栏编辑器、手机画布优先布局、底部工具栏与抽屉式素材/属性面板

## 测试

类型检查与生产构建：

```powershell
npm run typecheck
npm run build
```

浏览器验收脚本需要先启动开发服务器，并在本机可通过 CDP 接入一个 Chromium 浏览器：

```powershell
$env:CDP_URL="http://127.0.0.1:9338"
node scripts/browser-test.mjs
```

测试会覆盖封面、新建日记、照片拼贴模板、双图上传、标题正文、贴纸胶带、画布元素变换、天气心情、主题切换、自动保存、刷新恢复、完成动画、双页阅读、日历重开、PNG 导出和移动端页面，结果写入 `test-output/report.json`。

## 数据与限制

- 所有日记与上传图片均只保存在当前浏览器的 IndexedDB，不上传服务器。
- 天气与心情为手动标签，不接入真实天气 API。
- 示例日记会在本地首次打开且数据库为空时生成，并正常持久化。
- 第一版为单页日记编辑器，双页阅读由相邻日记组合呈现。
- 导出为当前单页画布的 2 倍分辨率 PNG。
